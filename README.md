# 🛒 Ο Tee mou, ti agorasa pali

**Ένα ψεύτικο e-shop σαν Temu/Shein/AliExpress για να σταματήσεις να αγοράζεις βλακείες!**

## 🎯 Τι είναι αυτό;

Είναι μια προσομοίωση ενός real e-shop τύπου Temu, όπου:
- Δημιουργείς ένα **ψεύτικο προφίλ**
- "Αγοράζεις" προϊόντα με **ψεύτικες τιμές**
- Βλέπεις **Live Tracking** της παραγγελίας σου κάθε φορά που μπαίνεις
- Όλα τα δεδομένα αποθηκεύονται στο **localStorage** του browser σου

## 🚀 Live Demo

Το site είναι ανεβασμένο στο **GitHub Pages**!

## 📂 Δομή

```
├── index.html              # Αρχική σελίδα
```

## 🔥 Features

- ⚡ Flash Sale countdown timer
- 🎉 Pop-up ειδοποιήσεις αγορών
- 💰 Κουπόνι έκπτωσης
- 📦 Live tracking με map
- ⭐ Ψεύτικες κριτικές
- 🚚 Free shipping progress bar
- 📱 Mobile responsive

## ⚠️ Σημείωση

Αυτό είναι ένα **ψεύτικο κατάστημα** για πλάκα! Κανένα πραγματικό ποσό δεν χρεώνεται, κανένα προϊόν δεν στέλνεται. Απλά μια προσομοίωση για να γελάσεις και να μην αγοράζεις βλακείες από αληθινά eshops! 😉
